# CampusRide: HCIN6222 POE

Clickable prototype for CampusRide, a website that helps students find or offer a seat on a regular commute to campus.

Student: [Nothando Khuzwayo] (ST10473018)
Module: HCIN6222

## Screens
- `index.html`: home page
- `signup.html`: sign-up
- `search.html` and `results.html`: find a ride
- `ride.html`: ride details and request
- `offer.html`: offer a ride
- `requests.html`: driver accepts or declines requests
- `trips.html`: my trips, cancel with undo, rate a trip
